# Editing Workflow

Before making any file edits:

1. Analyze the requested change.
2. Produce a detailed implementation plan.
3. List every file that would be modified.
4. Explain the purpose of each modification.
5. Do NOT edit any files yet.
6. Wait for explicit approval from the user.

Only after the user responds with:
- "approved"
- "go ahead"
- "implement"
- "green light"

may you begin making changes.

If approval has not been given, remain in planning mode and answer questions about the proposed changes.
